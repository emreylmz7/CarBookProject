# Car Book - Rent a Car App

The **Car Book Project** is an ASP.NET Core Web API application designed to streamline vehicle rental services through a modern and intuitive platform. Users can effortlessly list, rent, and return vehicles while benefiting from comprehensive account management and rental history tracking features.

![Car Book Project Overview](https://github.com/emreylmz7/CarBookProject/assets/65964414/a11d07eb-c9ba-4339-8d34-1df4529c0d30)

## Key Features

- **User-Friendly Interface**: Seamlessly list, rent, and return vehicles with an intuitive UI that enhances user experience.
- **Account Management**: Robust functionality for managing user accounts and rental history.
- **Real-Time Updates**: Leverage SignalR for live notifications and instant updates between the server and clients.
- **Secure Authentication**: JWT ensures secure user login and access control based on roles and permissions.
- **Data Integrity**: Use of Fluent Validation to ensure data validity and integrity.
- **Efficient Data Handling**: DTOs and Automapper streamline data transfer and object mapping.

## Implemented Design Patterns

- **Onion Architecture**: Organizes code into distinct layers (presentation, application, domain, and infrastructure) to enhance scalability, maintainability, and testability.
- **CQRS (Command Query Responsibility Segregation)**: Segregates read and write operations to optimize performance and scalability.
- **Mediator Design Pattern**: Promotes loose coupling by centralizing communication between components.
- **Repository Pattern**: Abstracts data access to separate business logic from data access code, improving testability and flexibility.

## Utilized Technologies

- **JWT (Json Web Token)**: For secure authentication and authorization.
- **SignalR**: For real-time communication and notifications.
- **DTO (Data Transfer Object)**: To streamline data transfer and enhance performance.
- **Fluent Validation**: For defining validation rules and ensuring data integrity.
- **Identity**: Manages user authentication, authorization, and account management.
- **Automapper**: Simplifies object-to-object mapping for better maintainability.
